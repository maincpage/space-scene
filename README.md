# 空间场景

分层 PNG 视差预览工具，支持本地项目与游客模式。

## 使用

1. 在完整程序文件夹中双击 `打开空间场景.cmd`，启动本地服务并打开网页。需要 Node.js 18+；在当前电脑上也会自动使用 Codex 自带的 Node.js。ZIP 请先“全部解压”。
2. 左侧选择已有项目，或输入名称“创建项目”。也可以保持默认的“游客模式”。点击“导入图片”选择一组 PNG、“导入文件夹”，或将图片拖到页面。
3. 图片加载后即可移动鼠标或拖动画面。手机在支持的浏览器中会自动尝试倾斜感应；需要授权时点击“开启倾斜感应”。点击“自动播放”可自动变化视角。

左侧项目对应程序目录下 `图` 中的普通文件夹，文件夹名就是项目名。当前电脑的保存位置为 `C:\Users\Administrator\Desktop\空间场景\图`，程序移到其他位置后使用新的同级 `图` 目录。外部添加文件夹后点击“刷新”即可显示。

选择项目后导入图片，会保存到 `图/项目名/`，之后点击项目即可重新打开。重新导入会替换整组图片，页面会先提示确认；校验失败不会覆盖原文件。新建的是空项目，创建后再导入。切换项目或游客模式会更换当前预览，游客图片请在切换前自行保留原文件。

游客模式可以导入、预览和调整参数，图片仅在当前页面内存中使用，不上传、不写入 `图` 目录。刷新后需重新导入。直接打开 `index.html` 时仅提供游客模式；使用项目功能请通过 CMD 启动。

`00.png` 是独立的整图，点击“整图对比”显示它，不参与视差叠加。`01.png` 是最底层，编号越大越靠前。项目图层按编号固定排列；游客模式可用箭头临时调整顺序。滑杆调整各层深度，深度越大位移越大。

“回正”恢复中心视角。“清空预览”只清除画面，不删除项目文件。“重置”恢复导入时的顺序和默认参数。参数自动存到当前浏览器，也可导出 / 载入 JSON；项目文件夹只保存图片，参数不会写入其中。

右侧“背景”可选黑底、白底，或上传 PNG / JPG / WebP 底图。底图居中铺满画布，保持比例，超出部分裁切，始终位于图层下面，不参与视差；透明底图的空白部分使用黑底。底图支持 25 MB 以内的文件，长边超过 4096 像素会等比缩小。背景及底图随当前场景自动保存在浏览器中，HTML、场景 PNG、静态 PNG 和参数 JSON 导出都会保留。底图存入浏览器的 IndexedDB，不占用项目中 `00.png`～`99.png` 的图层编号；清除浏览器站点数据会清除本地保存的设置与底图。

图层列表上方的“缩略图”可切换“图层边界”和“文档边界”。默认按实际可见内容放大缩略图；切到文档边界可查看图层在完整画布中的位置。这里只改变缩略图显示，原素材尺寸与坐标不变。

## 剪贴蒙版

每个图层下面都有“剪贴至”下拉框。例如在 `02.png` 的“剪贴至”中选择 `04.png`，02 只会显示在 04 的非透明内容范围内。02 和 04 各自的深度、钉点和变形仍然独立，裁切使用当前视角下 04 的实际轮廓，而不是导入时的固定轮廓。

可选择任意其他图层作为目标，选择“不剪贴”即可解除。目标自身的画笔 / 图片蒙版和剪贴关系也参与裁切，半透明边缘保留柔和过渡；不能剪贴到自身或形成循环关系。

剪贴关系不改变图层顺序。目标在上层时仍会遮住下面的图层；可以隐藏目标，仅使用它的轮廓裁切其他层。隐藏目标或编辑时“仅看选中层”不会使裁切失效。“整图对比”依旧显示原始 `00.png`。

剪贴关系随浏览器参数、JSON、场景 PNG 和互动 HTML 保存，静态 PNG 保留裁切后的画面。全局“重置”会解除全部剪贴关系。WebGL 不可用时，编辑页的平面视差及静态导出仍保留剪贴关系。

## 图层蒙版

在图层列表中点击“添加蒙版”，或打开“蒙版”页签选择图层，再点击“添加并编辑蒙版”。画面回到正面，默认保留其他图层，隐藏区域会露出下层和背景。

也可以在“蒙版”页签中选择图层，点击“导入蒙版图片”。支持 25 MB 以内的 PNG、JPG、WebP，彩色图片按亮度自动转为灰度：白色完全显示、黑色完全隐藏、灰色半透明，图片透明度会一同计算，完全透明区域按黑色处理。蒙版长边最多 2048 像素，图片按完整文档画布拉伸适配；建议使用与图层相同比例和坐标的图片。

导入会替换本层原有的画笔 / 图片蒙版，可以撤销。图片导入后仍可绘制隐藏 / 恢复、反相、启停或删除。图片数据存入浏览器 IndexedDB，参数中仅保存引用；导出 JSON、场景 PNG 和互动 HTML 时会内嵌完整灰度数据，因此在其他电脑也能恢复，无需另附蒙版图片。

- “隐藏”画笔遮住当前层，“恢复”画笔恢复原有内容。白色代表显示，黑色代表隐藏；恢复不会给原图透明区域添加内容。
- 可调整画笔大小、边缘硬度和不透明度。按 `X` 切换隐藏 / 恢复。滚轮缩放、抓手、空格平移和“定位图层”同样适用。
- “全部显示”“全部隐藏”“反相”作用于本层；取消“启用蒙版”可临时对比原图。“删除蒙版”恢复本层完整显示。
- “撤销蒙版”或画布中的 `Ctrl / ⌘ Z` 可撤销最近 30 步，包含笔画、启停、反相和删除。各层单独记录，与变形撤销独立。切换场景或重新载入参数后清空撤销记录。
- 点击“完成蒙版 · 预览”查看视差。蒙版与纹理一起跟随钉点和变形移动；编辑辅助线不会出现在导出中。

蒙版不改动原 PNG，随参数自动保存到当前浏览器，也包含在参数 JSON、互动 HTML、场景 PNG 和静态 PNG 导出中。旧参数没有蒙版时按完整显示载入。全局“重置”会清除蒙版，“重置本层变形”保留蒙版。浏览器存储不足时页面会提示，此时请导出参数或场景 PNG 保留编辑。蒙版预览栅格长边为 2048 像素，笔画坐标独立于视图缩放。

## 钉子与变形

1. 右侧“图层”页签中点击“编辑变形”，会切换到“钉子与变形”页签。画面回到正面，默认只显示该层，保留所选背景。手机可用顶部“项目”按钮打开项目栏。
2. 选“钉子”工具，在画面点击添加固定点，每层最多 12 个。拖动可移动钉点；点击面板中的钉点编号后，可用方向键微调、Delete 删除。也可使用“删除选中钉点”“清空钉点”。
3. “固定范围”控制钉点周围受约束的区域。钉点自身始终固定，周围网格逐渐过渡到自由移动。比如在头发根部下钉，再给发梢增加柔软弯曲。
4. “立体”预设增加表面起伏，“柔软”预设增加弯曲。可分别调整“立体起伏”和“柔软弯曲”，或使用凸起 / 凹陷画笔绘制局部深度。“擦平”清除画笔起伏；橙色标记凸起，蓝色标记凹陷。
5. 点击“完成编辑 · 预览”，移动鼠标、拖动或自动播放即可查看效果。编辑状态暂时停止视差，以便准确放置钉点；“仅看选中层”和“显示网格”仅影响编辑时的显示。

编辑画布底部有视图工具栏：滚轮或“− / +”缩放（50%～800%，100% 为适合当前预览区）；“抓手”拖动画布，也可按住空格或鼠标中键拖动。“定位图层”放大到当前图层的可见内容，“适应”或键盘 `0` 恢复完整画布。手机可用缩放按钮和抓手单指拖动。缩放围绕鼠标位置进行，放大后方向键微调钉点的步长也更小。视图缩放、平移不会修改图片、钉点或导出构图，完成编辑后回到完整预览。

“撤销编辑”保留当前图层最近 30 步。“平面”预设清除起伏和弯曲，保留钉点；“重置本层变形”同时清除本层钉点和起伏；全局“重置”清除所有层的钉点、变形与其他参数。

钉点坐标、画笔深度、固定范围和变形强度自动保存在当前浏览器，JSON 导出 / 载入也包含这些信息。旧版参数仍可载入。原 PNG 不被修改；游客模式仍不向项目目录写入图片或参数。

这是 PNG 网格驱动的 2.5D 效果：同一层的不同部位会有不同深度和弯曲，不需要准备完整模型。它不自动推断人物结构，也不生成侧面或背面；大角度转身和真实遮挡仍需要补充素材或完整 3D 模型。透明 PNG 的纹理与层叠通过 WebGL 绘制（[纹理说明](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Tutorial/Using_textures_in_WebGL)）。预览纹理按图层数限制显存，使用多级纹理改善缩小时的边缘质量，原图文件保持原始分辨率。

网格变形需要浏览器支持 WebGL。如果不可用，页面会提示并回退到原平面视差，钉子与变形控件暂时禁用；可尝试开启硬件加速后刷新。

## 导出与分享

完成编辑后，点击右上角“导出”：

| 格式 | 使用方式 | 保留内容 |
| --- | --- | --- |
| 互动场景 HTML | 将一个 HTML 文件交给对方，用浏览器打开即可互动，无需联网或启动本地服务；手机倾斜感应另受浏览器安全环境与授权限制 | 图层、背景 / 底图、钉点、变形、可见性、视差强度；支持手机倾斜、鼠标、触摸、方向键和整图对比 |
| 场景图片 PNG | 在普通看图软件里是一张静态图片；拖回本工具或通过“导入图片”选择单个文件即可恢复编辑 | 内嵌整图、全部原始图层、背景 / 底图及效果参数 |
| 静态图片 PNG | 用普通看图软件打开 | 当前视角的画面，不含编辑网格、钉点标记或场景数据 |

PNG 不能在普通看图软件中运行本工具的交互效果。HTML 的运行媒介是浏览器；场景 PNG 的运行媒介是本工具。场景 PNG 请按原文件传送，压缩、截图或二次保存可能移除内嵌数据。实现使用 PNG 的私有附加数据块，遵循 [PNG 数据块规则](https://www.w3.org/TR/png-3/#5Chunk-layout)。

静态导出及场景 PNG 的封面使用原画尺寸，长边最多 4096 像素。场景 PNG 内嵌的素材仍保持原始分辨率，因此文件比普通图片大。导入场景 PNG 时，游客模式只在本页恢复；项目模式会把内嵌素材保存为 `00.png`、`01.png` 等，并恢复当前浏览器内的效果参数。已有项目会先提示替换。

互动 HTML 以画面为主。图片右上角的半透明眼睛图标切换整图对比；手机 / 触屏设备旁边会显示手机图标，可开启或关闭倾斜感应。图标 3 秒不点击自动隐藏，点击画面重新显示；授权和感应状态仅短暂提示。没有标题栏或底部工具栏。互动 HTML 需要支持 WebGL 的浏览器，环境不支持时显示整图。手机上的聊天软件可能只显示 HTML 源码或预览，需交给浏览器打开。

## 图片要求

- 1 张整图和 1～20 张图层，总计不超过 150 MB。
- 文件名严格使用两位数字加小写扩展名：`00.png`、`01.png`、`02.png`……`99.png`。必须包含 `00.png` 与 `01.png`，其余编号可以不连续。
- 整图与所有图层使用相同画布尺寸和坐标，透明部分保留，不能分别裁到内容边缘。
- 支持横图、竖图和正方形，尺寸自动识别。
- 文件夹内只放本项目的 PNG，不含其他格式、说明文件或子文件夹。文件名不能重复，改扩展名不能把 JPEG 转成 PNG。
- 不符合规则的已有项目会显示原因，需要整理素材后重新打开；程序不会自动改动原素材。

不做深度推断或缺失信息补画。空间模式略微放大，为边缘预留移动余量；遮挡处缺少的内容仍可能显露，可降低视差强度。

## 手机

手机倾斜感应（常称陀螺仪视差）已同时接入编辑页和新导出的互动 HTML。支持直接接收方向数据的浏览器会自动尝试开启；iPhone / iPad 等需要显式授权的浏览器，编辑页点击“开启倾斜感应”，互动 HTML 点击右上角手机图标，再允许运动与方向访问。开启后以当前自然握持角度为中心，左右、前后倾斜即可查看视差。

触摸拖动暂时接管视角，松手后自动重新校准并继续倾斜感应。旋转横竖屏或回到页面时也会重新校准；编辑页还可以点击“回正”，互动 HTML 可按 Home。编辑钉点、切换到手动 / 自动播放时停止感应，避免干扰操作。开启了系统“减少动态效果”时不会自动尝试感应，仍可手动开启。

传感器需要浏览器认可的安全环境和权限，手机请优先使用 HTTPS 地址。普通局域网 `http://电脑IP:4173` 不能启用；本地 HTML 文件及聊天软件内置浏览器是否可用取决于浏览器，不能保证。权限被拒绝、不支持或 5 秒未收到有效数据时会提示原因，拖动仍然可用；允许权限后可再点手机图标重试。这些约束来自 [Device Orientation 浏览器规范](https://www.w3.org/TR/orientation-event/)。旧版导出的 HTML 需要重新导出才包含此修复。

已通过浏览器模拟方向事件、授权和触控的回归检查，尚未进行手机真机验证。

## 开发

纯 HTML / CSS / JavaScript，运行无外部依赖。Node.js 18+ 环境可运行 `npm start` 或 `node server.cjs`，访问 `http://127.0.0.1:4173`。默认只监听本机，可用 `PORT`、`HOST` 环境变量调整。CMD 启动会复用同端口、同目录的现有服务，后台服务随电脑关机结束。

`npm run check` 检查语法；`npm test`（或 `node --test tests/*.test.cjs`）测试导入规则、项目读写、失败保护、排序和视差计算。测试仅使用独立临时目录。

可选浏览器检查：安装 Playwright 及 Chromium 后运行 `node tests/browser-smoke.cjs`。也可设置 `BROWSER_CHANNEL=msedge` 使用已安装的 Edge。检查项目切换、导入、替换确认、游客模式无写入、整图对比和手机宽度布局，素材来自 `图/try01`，写入仅发生在临时目录。

`node tests/browser-deform.cjs` 进一步验证多钉点编辑、撤销、画笔、参数导入导出、真实 GPU 像素中的固定点、触控输入和旧参数迁移。`tests/mesh-math.test.cjs` 验证固定约束、局部变形与画笔边界。

`node tests/browser-export.cjs` 验证三种导出、HTML 断网运行、场景 PNG 作为普通图片打开、图层与变形往返恢复、损坏数据保护和手机布局。`tests/scene-package.test.cjs` 验证 PNG 数据块完整性与参数校验。

`node tests/browser-canvas-tools.cjs` 验证背景持久化与导出像素、静止底图、两种缩略图、800% 缩放后的钉点坐标、滚轮定点缩放、抓手 / 空格平移，以及手机触控。

`node tests/browser-mask.cjs` 验证蒙版画笔、独立图层、撤销、反相、启停、缩放坐标、参数持久化、三类导出与触控。`tests/layer-mask.test.cjs` 验证旧参数兼容与损坏蒙版校验。`layer-mask.js` 为共用蒙版模块。

`node tests/browser-clipping.cjs` 验证任意图层剪贴、不同视差和变形下的 GPU 裁切像素、隐藏目标与多级剪贴、彩色图片转灰度、2048 像素蒙版持久化、导出恢复和失去 GPU 后的回退。`tests/layer-clip.test.cjs` 验证循环引用、图片数据校验和场景打包；`layer-clip.js` 为剪贴校验与平面回退模块。

`node tests/browser-tilt.cjs` 验证编辑页与离线互动 HTML 的手机感应、授权点击、视差像素变化、拖动恢复、横屏校准及失败回退。`tests/scene-tilt.test.cjs` 验证授权取消、超时、后台恢复和监听清理。

编辑 `app-main.js`、`scene-tilt.js`（共用倾斜感应）、网格 / 编辑器模块、`scene-package.js`、`scene-export.js` 或 `export-player.js` 后，运行 `node build.cjs`（或 `npm run build`），将模块和独立播放器打包到页面入口 `app.js`。`npm start` 会先自动构建。提供的 `app.js` 已构建好，直接双击 CMD 或打开 HTML 即可使用。

文件：`index.html`（页面）、`styles.css`（样式）、`app-main.js`（场景交互源码）、`app.js`（构建后的浏览器入口）、`build.cjs`（打包）、`image-files.js`（导入与排序）、`scene-math.js`（坐标计算）、`mesh-math.js`（网格约束与深度）、`mesh-renderer.js`（纹理绘制）、`layer-editor.js`（钉点和画笔编辑）、`server.cjs`（本地服务）、`project-store.cjs`（项目读写）、`start.ps1`（Windows 启动）。
